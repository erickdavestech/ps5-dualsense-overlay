# Upstream documentation

The documents in this folder come from [Common FPS for PS5](https://github.com/porhe911/Common-FPS-for-PS5)
by porhe911 and are kept unchanged for reference and attribution. They describe the original FPS
overlay and its development, not ps5-dualsense-overlay.

- `UPSTREAM_README_CommonFPS.md` — the upstream README.
- `upstream-releases/` — the upstream release notes.
- The remaining files — upstream design notes, test plans and hardware evidence. Some of them are used
  by `tools/check_v1_source_gate.py`.

For this project, start with the main [README](../README.md).
