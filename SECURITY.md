# Security Policy

## Supported versions

Only the latest release receives fixes.

## Reporting a problem

Do not open a public issue for security problems. Report them privately through GitHub:
open the repository's **Security** tab and choose **Report a vulnerability**.

Please include the overlay version, console model, system software version, homebrew enabler and the
steps to reproduce. You will get an answer as soon as possible, and fixes will be credited unless you
prefer otherwise.

## Scope

In scope: problems in this project's code, for example behavior that corrupts memory of a process it
should not touch, writes outside the documented paths, or crashes the system UI in a reproducible way.

Out of scope: vulnerabilities in the PS5 system software, in homebrew enablers or in payload loaders —
report those to their respective projects. This project does not accept or publish exploits.
